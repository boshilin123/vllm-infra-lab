# Prefill 对照：1024/128 c8-mns8

## 实验问题

相对同卡 Short 校准，只把 Prompt 从 256 增加到 1024 tokens，输出仍为 128，验证更多 Prefill 工作对 TTFT、TPOT、吞吐和 KV Cache 的影响。

事前假设是：输出吞吐下降、P95 TTFT 上升；P95 TPOT 应接近基线或小幅上升。长负载按实验前冻结的 Long SLO v1 判断。

## 实验配置

- 模型：Qwen3-8B BF16，vLLM 0.9.1
- 输入/输出长度：1024/128 tokens
- 客户端并发 / 服务端 `max-num-seqs`：8/8
- 每轮预热/正式请求：10/60，正式重复 3 次
- 节点、GPU UUID：qhvgpu1，`GPU-5e5590e5-51de-1c1c-6c72-4cbe1477e116`
- Git commit：`da604fe15147b72a7341b7370eef168eef1d8c05`
- 正式随机种子：`107042/107043/107044`

## 三轮中位结果

| 指标 | 中位数 | CV |
| --- | ---: | ---: |
| 请求吞吐 | 1.085972 req/s | 0.1064% |
| 输出 Token 吞吐 | 139.004387 tok/s | 0.1064% |
| 总 Token 吞吐 | 1251.039484 tok/s | 0.1064% |
| Mean TTFT | 721.213661 ms | 3.8862% |
| P95 TTFT | 1464.013822 ms | 10.2739% |
| Mean TPOT | 49.652521 ms | 0.5805% |
| P95 TPOT | 53.146928 ms | 0.1201% |
| Mean E2E | 7024.822717 ms | 0.1141% |
| P95 E2E | 7354.942444 ms | 0.3082% |

三轮均为 60/60 请求成功，失败数为 0；时长分别为 55.27、55.25、55.16 秒。吞吐极稳定，但 P95 TTFT 的 CV 为 10.27%，说明 Chunked Prefill 下的首 Token 尾延迟对轮次更敏感。

## 与同卡 Short 对比

| 指标 | 256/128 | 1024/128 | 相对变化 |
| --- | ---: | ---: | ---: |
| 输出吞吐（tok/s） | 180.649355 | 139.004387 | -23.05% |
| 总 Token 吞吐（tok/s） | 541.948065 | 1251.039484 | +130.84% |
| P95 TTFT（ms） | 486.414863 | 1464.013822 | +200.98% |
| P95 TPOT（ms） | 41.948177 | 53.146928 | +26.70% |
| P95 E2E（ms） | 5496.814455 | 7354.942444 | +33.80% |

输出吞吐只计算生成 Token。Prompt 增长后，GPU 把更多时间用于 Prefill，所以输出吞吐下降；总 Token 吞吐因为把输入 Token 也计入而大幅上升，不能把它解释成 Decode 生成能力提高。

## Chunked Prefill 与 KV Cache

首波 Prompt 合计 `8 × 1024 = 8192` tokens，高于启动日志中的 `max_num_batched_tokens=2048`，需要多个调度块推进。监控曾短暂观察到 running/waiting 的重新分配，随后回到 `running=8、waiting=0`；这里的 waiting 可以由 token 调度预算产生，并不要求客户端并发超过 `max-num-seqs`。

KV Cache 采样峰值约 40.36%，与满长度简单上界 `8 × (1024+128) / 22832 ≈ 40.37%` 接近。它说明活动序列接近预计的 Token 占用，不说明算力或批处理效率已经最优。

## Long SLO v1

| 指标 | SLO | 实测 | 判断 |
| --- | ---: | ---: | --- |
| 请求成功率 | ≥99% | 100% | PASS |
| P95 TTFT | ≤1500 ms | 1464.014 ms | PASS |
| P95 TPOT | ≤55 ms | 53.147 ms | PASS |
| P95 E2E | ≤13 s | 7.355 s | PASS |

P95 TTFT 只比阈值低约 36 ms，且 P99 TTFT 中位数为 1723.975 ms，不能描述为首 Token 体验宽裕。结果支持“Prompt 增长主要提高 Prefill/TTFT 压力”的假设，同时表明它也使 TPOT 上升约 26.7%，不能说 Decode 完全不受影响。
