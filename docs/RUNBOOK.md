# Runbook

本文档将在 Phase 1 按实际操作补全，所有命令必须能够从干净环境复现。

## 部署前检查

- 记录 Git commit、Kubernetes、驱动、CUDA、GPU、模型与镜像版本。
- 检查目标节点空闲 GPU 和并存工作负载。
- 检查模型挂载只读且路径不写入公开仓库。

## 部署与验证

1. 应用 Namespace 和服务清单。
2. 等待 Pod Ready，并记录模型加载时间。
3. 调用 `/v1/models`。
4. 发送一次最小补全请求。
5. 检查 `/metrics` 和 DCGM 指标是否可查询。

## 故障记录模板

- 现象与时间；
- 配置和输入；
- Events、容器日志和关键指标；
- 根因与验证方法；
- 修复、回滚和适用边界。
